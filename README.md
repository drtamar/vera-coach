# Vera

Not a to-do list. One voice that supplies the start button — and stays when you drift off the thing you chose.

No streaks. No “you are behind.” Completions stay on a record that does not decay. A brain that forgets good days needs evidence, not badges.

First user is the person building it. Later, other people with the same hole in initiation. Sensitive context stays on this side of the wall.

Work in progress. The invitation is how the product thinks, not a dump of how it is wired.

## Status

Public repo is the name and the door. Source lands here in pieces. Supporting design documents stay off this remote.
